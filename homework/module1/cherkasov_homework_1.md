## Завдання 1. Базові команди

### 1.1. Показати вміст домашнього каталогу

```bash
cd ~
ls
```

**Пояснення:**  
Команда `cd ~` переводить користувача у домашній каталог. Команда `ls` показує список файлів і каталогів у поточному каталозі.

---

### 1.2. Перейти у каталог `Downloads` і показати його вміст

```bash
cd Downloads
ls
```

**Пояснення:**  
Команда `cd Downloads` переходить у каталог `Downloads`, який знаходиться всередині домашнього каталогу. Команда `ls` показує його вміст.

---

### 1.3. Створити порожній файл без використання `touch`

```bash
cat > empty_file.txt
```

Після введення команди потрібно одразу натиснути:

```text
Ctrl + D
```

**Пояснення:**  
Команда `cat > empty_file.txt` створює файл через перенаправлення виводу. Якщо нічого не вводити в файл і одразу натиснути `Ctrl + D`, буде створено порожній файл. Команда `touch` при цьому не використовується.

---

### 1.4. Переглянути вміст файлу

```bash
cat empty_file.txt
```

**Пояснення:**  
Команда `cat` виводить вміст файлу в термінал. Оскільки файл порожній, після виконання команди текст не буде виведений.

---

### 1.5. Перейти у домашній каталог абсолютним шляхом

```bash
cd /home/$USER
```

**Пояснення:**  
Абсолютний шлях починається з кореневого каталогу `/`. Команда `cd /home/$USER` переходить у домашній каталог поточного користувача через абсолютний шлях.

---

### 1.6. Перейти у домашній каталог відносним шляхом

```bash
cd Downloads
cd ..
```

**Пояснення:**  
Спочатку команда `cd Downloads` переходить з домашнього каталогу в каталог `Downloads`. Потім команда `cd ..` повертає на один рівень вище, тобто назад у домашній каталог. Це приклад переходу відносним шляхом, бо шлях не починається з `/`.

## Завдання 2. Робота з документацією

### 2.1. Виконані команди

```bash
man ls
help cd
man cat
man man
cp --help
mv --help
```

**Пояснення:**  
Ці команди використовуються для перегляду документації та довідки по командах Linux:

- `man ls` — відкриває сторінку довідника для команди `ls`;
- `help cd` — показує довідку для вбудованої команди оболонки `cd`;
- `man cat` — відкриває сторінку довідника для команди `cat`;
- `man man` — відкриває документацію по самій команді `man`;
- `cp --help` — показує коротку довідку по команді `cp`;
- `mv --help` — показує коротку довідку по команді `mv`.

---

### 2.2. Який ключ `ls` показує приховані файли?

Ключ, який показує приховані файли:

```bash
ls -a
```

**Відповідь:**  
Ключ `-a` показує всі файли, включно з прихованими. У Linux приховані файли починаються з крапки, наприклад `.bashrc`, `.profile`, `.config`.

---

### 2.3. Який ключ у `cat` нумерує рядки?

Ключ, який нумерує рядки:

```bash
cat -n filename.txt
```

**Відповідь:**  
Ключ `-n` нумерує всі рядки файлу при виведенні його вмісту в термінал.

---

### 2.4. Чим відрізняються `man` і `--help`?

**Відповідь:**  
`man` відкриває повну сторінку документації для команди. У ній зазвичай є опис команди, синтаксис, доступні ключі, приклади використання та додаткова інформація.

`--help` виводить коротку довідку безпосередньо в термінал. Зазвичай там показані основні ключі та короткий опис їх призначення.

Основна різниця: `man` дає більш повну документацію, а `--help` — швидку коротку підказку по команді.

## Завдання 3. Міні-сценарій

### Сценарій із команд

```bash
cd ~
cd Downloads
cat > scenario_file.txt
ls
cd ..
cd Downloads
man cat
cat scenario_file.txt
```

Після команди:

```bash
cat > scenario_file.txt
```

потрібно одразу натиснути:

```text
Ctrl + D
```

щоб створити порожній файл.

---

### Пояснення сценарію

1. `cd ~` — перехід у домашній каталог.
2. `cd Downloads` — перехід у каталог `Downloads`.
3. `cat > scenario_file.txt` — створення файлу `scenario_file.txt` без команди `touch`.
4. `ls` — перегляд списку файлів у каталозі `Downloads`.
5. `cd ..` — перехід в інше місце, тобто на рівень вище, у домашній каталог.
6. `cd Downloads` — повернення назад у каталог `Downloads`.
7. `man cat` — перегляд документації для команди `cat`.
8. `cat scenario_file.txt` — перегляд вмісту створеного файлу.

**Висновок:**  
У цьому сценарії використані базові команди Linux для переходу між каталогами, створення файлу, перегляду списку файлів, повернення назад до попереднього каталогу та перегляду документації команди.
